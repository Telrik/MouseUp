Early experimental build for Ubuntu 24.04 x86-64 using X11. This beta has limited testing and is separate from the main Windows release.

Download `mouseup-ubuntu-x11-0.2.0-beta1-amd64.deb` and open it with Ubuntu's package installer, or run `sudo apt install ./mouseup-ubuntu-x11-0.2.0-beta1-amd64.deb`.

The package contains 16 original cursor shapes and 12 colors, per-application hotkeys, and an optional system tray. Some games draw a cursor inside their own frame, which may remain visible under MouseUp's overlay. Wayland is unsupported; fullscreen and compositor compatibility varies.

The included cursor artwork originates from YoloMouse; its redistribution rights have not been established. MouseUp is independent and not affiliated with YoloMouse.
